# v1.0.0 - İlk Public Kaynak Kod Sürümü

## Kapsam

Bu sürüm, **Vortex Yapay Zeka Asistanı** projesinin ilk açık kaynak (public) kaynak kodu yayınını temsil etmektedir. Repository, GitHub üzerinde güvenli şekilde paylaşılabilecek dosyaları içerecek şekilde hazırlanmıştır. Yayınlanan dosyaların kapsamı `docs/PUBLIC_EXPORT_MANIFEST.json` içerisinde tanımlanmıştır.

Bu sürüm yalnızca kaynak kodu ve dokümantasyonu içerir. Derlenmiş uygulamalar, kurulum paketleri, dağıtım dosyaları veya çalıştırılabilir çıktılar bu sürüme dahil değildir.

## Dahil Edilenler

- İlk public kaynak kodu sürümü.
- GitHub için düzenlenmiş proje yapısı.
- Türkçeleştirilmiş ve güncellenmiş dokümantasyon.
- README ve proje tanıtım sayfası.
- Kurulum ve başlangıç dokümantasyonu.
- Mimari ve proje yapısı dokümantasyonu.
- Güvenlik politikası.
- Sürüm notları.
- Arayüz ve kurulum ekran görüntüleri.
- GitHub üzerinde paylaşılmaya uygun public repository yapısı.

## Dokümantasyon

- README tamamen yeniden düzenlendi.
- GitHub için profesyonel görünüm sağlandı.
- Dokümantasyonlar Türkçeye uyarlandı.
