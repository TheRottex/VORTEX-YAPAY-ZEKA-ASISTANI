# v1.0.1 - Public Kaynak Kod Güncellemesi

## Kapsam

Bu sürüm, public kaynak kodu dağıtımına yönelik bakım ve iyileştirme güncellemesidir. Yayınlanan dosyaların kapsamı `docs/PUBLIC_EXPORT_MANIFEST.json` içerisinde tanımlanmıştır. Bu sürüm yalnızca kaynak kodu ve dokümantasyonu kapsar.

## Yapılan Güncellemeler

- Public cihaz görev tamamlama kayıt yapısı sadeleştirildi.
- Tamamlama isteklerinde yalnızca gerekli cihaz bilgileri ve işlem geçmişi saklanacak şekilde düzenleme yapıldı.
- HTTP tamamlama uç noktalarının durum kodları netleştirildi.
- Tekrarlanan isteklerde idempotent davranış iyileştirildi.
- DryRun senaryoları için public test kapsamı genişletildi.
- Endpoint bazlı hız sınırlama (Rate Limiting) mekanizması güncellendi.
- Public repository hijyen kontrolleri iyileştirildi.
- Dosya manifesti ile repository içeriğinin birebir doğrulanması sağlandı.

## Yayın Öncesi Not

Repository yayınlanmadan önce `docs/PUBLIC_EXPORT_MANIFEST.json` dosyası gözden geçirilmeli ve yalnızca manifest içerisinde tanımlanan kaynak kodu ile dokümantasyon dosyaları Git'e eklenmelidir. Build çıktıları, derlenmiş dosyalar ve public sürüme dahil edilmemesi gereken içerikler kesinlikle yayınlanmamalıdır.
