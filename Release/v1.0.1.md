# v1.0.1 public source export

## Scope

This is a source-only public-export revision. Its exact included-file list is `docs/PUBLIC_EXPORT_MANIFEST.json`; it contains no build output, archive, package, or desktop package claim.

## Included source changes

- Public device-job completion requests persist only device credentials, success, code, message, and timeline.
- Completion route semantics are explicit: invalid device credentials return 401; valid-device missing or pending jobs return 404; claimed jobs complete with 200; completed-job retries return original persisted data without overwriting; other state guard failures return 409.
- Public integration coverage exercises the actual HTTP route, owner isolation, retry idempotency, and queued `DryRun` preservation.
- Registration, login, device registration, action queueing, claim, and completion use endpoint-specific fixed-window limits keyed only by the direct peer IP; rejected requests return generic 429 with no queue.
- Repository hygiene uses the exact positive file manifest, permits only this release note under `Release`, rejects operational indicators, and requires bidirectional equality with `git ls-files`.

## Exclusions and non-claims

- No Desktop, LocalAgent, Worker, Hermes, Tailscale, Docker, deploy, Admin, private Web, runtime configuration, credential, database, log, binary, archive, or package material is part of this revision.
- This source export does not claim a Pardus installation, package build, package upgrade/uninstall, live device action, OAuth flow, voice flow, deployment, or GitHub release asset.

## Owner action before publication

The hygiene test deliberately fails while public source files remain untracked. The owner must review the exact manifest and stage only those listed source/documentation files. Do not stage build output or other excluded material.
