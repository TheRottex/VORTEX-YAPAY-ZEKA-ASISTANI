3. Private environment contract

Private environment file user-owned, repository dışı ve restrictive permission ile tutulur. VORTEX_WORKER_TOKEN ve provider key yalnız bu private dosyada/secret manager'da tutulur; değerlerini bu rehbere, repository'ye veya loglara yazma. Seed içeriği ayrı private dosyada kalır.
DeğişkenAmaç
VORTEX_SERVER_URLPublic Server HTTPS origin.
VORTEX_WORKER_IDServer'ın kabul ettiği Worker kimliği.
VORTEX_WORKER_TOKENZorunlu HMAC secret. CLI argümanı değildir; child/container'a geçmez.
VORTEX_WORKER_DATAPrivate, durable per-user workspace root.
VORTEX_HERMES_EXECUTION_MODEprocess veya docker. Geçersiz değer fail-closed.
VORTEX_DOCKER_CLI_PATH, VORTEX_DOCKER_HERMES_IMAGEDocker CLI/image seçimi.
HERMES_CONFIG_SEED_PATH, HERMES_ENV_SEED_PATHRepository/data root dışındaki private Hermes seed dosyaları.
VORTEX_REQUIRE_PRIVATE_SERVER_ENDPOINTPrivate endpoint guard. Public HTTPS origin kullanılırken false kalır.

Secret-free variable şablonu: vortex-hermes-worker.env.example.

Tailscale/private endpoint doğrulanmadan guard değerini true yapma. Bu durumda normal public hostname/IP fail-closed reddedilir.

5. Docker image readiness

[RUNTIME DEĞİŞTİRİR] Build Docker image state oluşturur. [GEÇİCİ DOĞRULAMA] --rm smoke container'ı işlem sonunda siler.

cd <Vortex-Clean-Source>
test -f docker/hermes/Dockerfile
docker build -t <IMAGE_TAG> -f docker/hermes/Dockerfile .
docker run --rm <IMAGE_TAG> --help
docker image inspect <IMAGE_TAG>

Bu sadece image/entrypoint readiness smoke kontrolüdür. Server → Worker → Hermes gerçek E2E kanıtı değildir.

  • Image bind-mounted /workspace ve HERMES_HOME izinlerini kısa süre root ile düzeltir, sonra non-root hermes kullanıcısına iner.
  • Container one-shot, --rm, bridge network ve dar bind mount sınırlarıyla çalışır.
  • Docker daemon, image veya güvenli resource limit yoksa Worker gerçek failure bildirir; direct-process fallback yoktur.
  • Worker yalnız allowlisted model-router environment değerlerini container'a geçirebilir. Worker HMAC token geçmez.

7. Readiness ve kontrollü doğrulama

# [SALT-OKUNUR] Public Server Worker readiness — Worker başlatmaz
curl -fsS <PUBLIC_SERVER_ORIGIN>/health/worker

# [SALT-OKUNUR] Son Worker journal; paylaşmadan önce secret redaksiyonu yap
journalctl --user -u vortex-hermes-worker -n 200 --no-pager
tail -n 200 "$HOME/vortex-worker/data/logs/worker.log" 2>/dev/null || true
  1. Önce Docker/image readiness doğrula.
  2. Worker başlat; heartbeat/readiness görünmesini bekle.
  3. Yalnız owner-authenticated kontrollü job gönder.
  4. Gerçek Server → Worker → Hermes sonuç metnini ve owner-only erişimi doğrula.
Queue accepted, Worker job completed veya LocalAgent response tek başına masaüstü görsel eylemi doğrulamaz. Gerçek desktop değişimi kullanıcı gözlemi veya frame/screenshot kanıtı gerektirir.

8. Failure triage

DurumDoğru davranış
Docker daemon/image unavailableWorker unready/failure bırak. Process mode'a otomatik geçme.
Seed dosyası unavailable veya unsafeJob fail-closed olur. Dosya konumu/permission düzelt; içeriği loglama.
Provider/model router unavailableGerçek provider failure raporla. Sonuç uydurma.
Public Server health var, Worker health yokWorker environment, outbound connectivity, Worker ID/token ve Docker readiness kontrol et.
Private endpoint guard rejectPublic HTTPS topology'de guard false kalır. Private endpoint yalnız ayrı doğrulanmış transport aşamasında kullanılır.
IPv6 bağlantısı başarısız, IPv4 erişilebilirÖnce curl -4 ve curl -6 ile ayrımı doğrula; geçici ağ bypass'ını kalıcı Worker ayarı yapmadan önce operator onayı ve kalıcı ağ çözümü gerekir.
CLIProxy endpoint/port belirsizGerçek private Worker config'teki endpointi doğrula. Eski örneklerdeki portu körlemesine kopyalama; container-to-host erişimini seçilmiş endpoint ile test et.

curl -4 -I --connect-timeout 10 <PUBLIC_SERVER_ORIGIN>

9. Worker rollback

[RUNTIME DEĞİŞTİRİR] Önce aktif ve eski release dizinlerini incele. İlk olay müdahalesinde hiçbir release silme.

readlink -f "$HOME/vortex-worker/current"
ls -ld "$HOME/vortex-worker/releases"/*

KNOWN_GOOD_RELEASE="<OLDER_RELEASE_DIRECTORY>"
test -f "$KNOWN_GOOD_RELEASE/Vortex.HermesWorker.dll"
ln -s "$KNOWN_GOOD_RELEASE" "$HOME/vortex-worker/current.rollback"
mv -Tf "$HOME/vortex-worker/current.rollback" "$HOME/vortex-worker/current"
systemctl --user restart vortex-hermes-worker
systemctl --user status vortex-hermes-worker --no-pager -l
